# QuickNotes

QuickNotes is a simple browser-based note-taking app for quickly capturing personal, work, and study notes. It keeps notes in the browser so they remain available after a refresh, while providing search and category labels to make notes easy to find.

## Features

- Add notes of up to 200 characters in Personal, Work, or Study categories.
- View each note with its category, creation date, and a delete button.
- Search note text without case sensitivity.
- Save notes with localStorage so they persist between page refreshes.
- Clear all notes after confirming the action.
- Use a responsive layout that adapts to smaller screens.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Add a note and start using QuickNotes; no installation or server is needed.
